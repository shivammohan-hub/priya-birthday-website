PRIYA'S BIRTHDAY WEBSITE

CONTENTS
- index.html: complete Tailwind CSS + JavaScript website
- assets/: put your photos and music here

ADD 10-15 PHOTOS
Copy your photos into assets/ and rename them:
photo-01.jpg
photo-02.jpg
photo-03.jpg
...
photo-15.jpg

You can use fewer than 15 photos. The gallery will show placeholders for photos you have not added. JPG is the expected format. If your photos are PNG or WEBP, convert them to JPG or change the image paths in the photos array in index.html.

ADD BACKGROUND MUSIC
Put an MP3 file in assets/ and name it music.mp3. The visitor must tap "Play music" once because browsers block autoplay audio.

PREVIEW
Open index.html with VS Code Live Server. Internet access is needed for Tailwind CDN and Google Fonts.

PUBLISH WITH GITHUB PAGES
Upload index.html and the entire assets folder to the root of your GitHub repository. Commit the changes. Then open Settings > Pages, choose Deploy from a branch, select main and /(root), and Save. Wait for the deployment to finish.

PERSONALIZE
Edit the letter paragraphs in the letterModal section, and edit the four "Little things I adore" cards in index.html.
